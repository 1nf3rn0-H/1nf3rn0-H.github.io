## Visibility is a measurable property

Defenders often know which behaviours they want to detect, but not whether the necessary telemetry survives the route from host to platform. A visibility probe makes that gap concrete.

## Design

The probe observes selected kernel tracepoints, adds container context, and records a compact event model. The goal is not to collect everything; it is to answer whether a future detection has the evidence it needs.

## What to measure

Useful measurements include event loss, field completeness, enrichment delay, and the distance between a collected event and an investigation-ready record. These describe the practical reliability of the telemetry pipeline.
